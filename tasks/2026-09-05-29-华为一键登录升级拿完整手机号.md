# 任务 29：华为一键登录升级为「拿完整手机号」版本

日期：2026-09-05
提交：`bcec4fd`（代码）+ 本次 docs 提交

## 一、背景

用户确认「华为账号一键登录（quickLoginAnonymousPhone）」企业权限已通过审核，可升级为获取**完整手机号**的一键登录闭环，替代此前的「unionID 直登」过渡方案。

## 二、服务端接口调研（关键）

通过华为官方 Java 服务端 Skill（`HarmonyOS_Samples/accountkit-samplecode-serverdemo`）确认了 `/oauth2/v6/quickLogin/getPhoneNumber` 的**精确契约**：

```
POST https://account-api.cloud.huawei.com/oauth2/v6/quickLogin/getPhoneNumber
Content-Type: application/json

请求体：{ "code": "<authorizationCode>", "clientId": "<client_id>", "clientSecret": "<client_secret>" }
响应体：{ "openId", "unionId", "phoneNumber", "phoneNumberValid", "purePhoneNumber", "phoneCountryCode" }
```

要点：
- 域名是 `account-api.cloud.huawei.com`（与普通授权码模式的 `oauth-login.cloud.huawei.com` **不同**）
- 请求/响应字段均为 **camelCase**（`clientId`/`clientSecret`/`openId`/`unionId`/`phoneNumber`）
- `phoneNumber` 带国家码（008611122223333），`purePhoneNumber` 为纯号（11122223333），入库取纯号

## 三、改动内容

### 后端

- `HuaweiAccountClient.java`：
  - 新增 `quick-login-url` 配置（默认内置，无需改 yml）
  - 新增 `quickLoginByCode(code)`：JSON body 调 getPhoneNumber，解析 openId/unionId/phone（纯号优先，回退带码号），unionId 为空抛业务异常
- `HuaweiLoginBo.java`：新增 `authorizationCode` 字段，注释更新为三模式优先级（authorizationCode > code > unionId）
- `AppAuthServiceImpl.huaweiLogin`：`authorizationCode` 非空走一键登录换号；否则 `code` 非空走普通授权码；最终按 UnionID 查绑定/自动注册，手机号合并逻辑复用

### 前端

- `AuthApi.ets`：`HuaweiQuickLoginBody` 新增 `authorizationCode`；`huaweiQuickLogin(authorizationCode, unionId, openId)`
- `LoginPage.ets`：`handleQuickLogin` 取 `credential.authorizationCode ?? ''`，三参直传后端

## 四、验证方式

- 后端：推送后 GitHub Actions `api-ci` 编译验证
- 前端：DevEco Build 验证 `credential.authorizationCode ?? ''` 与三参调用
- 真机：一键登录 → 后端日志应出现 `huawei quickLogin getPhoneNumber resp={...}`，返回 unionId + purePhoneNumber，`sh_user.phone` 写入完整手机号

## 五、变更补充（commit `967112b`）

按华为一键登录 UX 规范补充「匿名手机号展示」：

- `HuaweiAuthService.getQuickLoginAnonymousPhone(context)`：新建，`executeRequest` + scope `quickLoginAnonymousPhone` + `forceAuthorization=false`，读 `response.data?.extraInfo?.quickLoginAnonymousPhone`，拿不到返回空串不阻断登录
- `LoginPage.ets`：新增 `@State anonymousPhone`，`aboutToAppear` 调 `fetchAnonymousPhone()` 异步拉取；一键登录按钮上方条件渲染打码手机号 + “华为账号绑定号码”标题
