1. **华为一键登录（取手机号）**：文档 `account-phone-unionid-login` 属企业专属（scope `quickLoginAnonymousPhone`），需 3 工作日审核；当前已实现的 `openid+profile` 授权码登录无需申请，两者不冲突。已写好申请文案（见 doc/17 第二节）。
2. **食物识别**：百度免费额度够用；彻底免费走 PaddleClas 本地；换国内大厂走腾讯云/阿里云菜品识别。
3. **"吃什么"决策**：全部基于自有 `sh_dish` + 自研推荐/抽签引擎，不依赖外部饮食推荐 API；英文 API 只作营养补全。
4. **项目定位端正**：社区发现 + 转盘决策 + 健康推荐三大支柱。
