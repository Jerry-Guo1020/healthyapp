## 二、编译验证（服务器）

- 服务器已有 **JDK 17.0.19 + Maven 3.8.7**（无需安装）。
- 发现服务器是「多项目共用机器」：跑着 3 个 MySQL 8.4、1 个 Redis、RustDesk、easytier、derper、alist、node、另一个 RuoYi 后端等，**空闲内存仅 ~385Mi、swap 已打满**。
- 采取**无损方案**：新增 4G swapfile（`/swapfile`，总 swap 5.9G），不碰任何现有服务；编译串行 `-T 1` + 限堆 `MAVEN_OPTS=-Xmx1024m` + `-DskipTests`。
- 修复 3 处编译错误：
  1. `ruoyi-admin/pom.xml` 依赖 `shanheng-app` 缺 version → 根 pom `dependencyManagement` 补充 `shanheng-app`（`${revision}`）。
  2. `ShFavorite.java` 此前被截断 → 重写完整实体。
  3. 15 个 `sh_*` 表主键原为 `AUTO_INCREMENT`，与实体雪花主键（`@TableId`）冲突 → SQL 统一去除 `AUTO_INCREMENT`，对齐 RuoYi 雪花体系。
- 结果：**BUILD SUCCESS**，产物 `ruoyi-admin/target/ruoyi-admin.jar`（157M）。编译后内存自动释放。
