# 任务 13：健康数据模块 + 智能推荐模块（承接华为手表数据）

- 日期：2026-09-01
- 关联 commit：后端 `c052f29`、App 前端 `0ae3cd0`
- 目标：落实最初「对接华为手表数据」的落地点 —— M4 健康数据 + M5 智能推荐，跑通「健康数据 → 推荐规则引擎 → 个性化菜品推荐」闭环

## 一、定位与策略

回顾 `doc/07-华为服务接入方案.md`、`doc/03-核心功能模块设计.md`，确认「华为手表数据」落地点为：

1. **M4 健康数据模块**：通过华为 Health Kit 拉取步数/睡眠/心率/压力/活动量 → 汇总为 `sh_health_summary` 摘要
2. **M5 智能推荐模块**：基于健康摘要 + 用户偏好/忌口 + 推荐规则 → 输出个性化菜品

**关键策略**：Health Kit 真实手表数据受「受限权限审核」约束（需企业资质 + 华为审核），MVP 阶段用手动健康状态录入兜底，但**统一走同一条 `sh_health_summary` 摘要与同一套推荐规则引擎**——后续打通华为手表后只需替换「数据来源」，推荐链路无需改动。

## 关键决策记录

- **手动录入兜底，统一摘要 + 统一规则引擎**：Health Kit 受限权限后置，MVP 用手动 MANUAL 来源先跑通推荐闭环，后续无缝切换
- **健康 Tab 复用 `@Prop @Watch` 激活刷新模式**：与其他 Tab 保持一致
- **推荐结果字段用独立 @State 基本类型 + 数组整赋**：避免嵌套对象属性不刷新
- **App 端不依赖华为 SDK**：当前阶段纯 HTTP 上报摘要，Health Kit 由 P1 阶段在华为侧封装后写入同一张表
