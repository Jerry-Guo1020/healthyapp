# 任务日志 2026-08-26-02 · 架构调整：合并为单 Spring Boot 后端

## 一、任务目标

回应用户关键问题："RuoYi 后端也是 Spring Boot，能不能就用一个 Spring Boot 完成全部后端操作？"，并据此调整架构方案与相关文档。

## 二、决策结果

**采用单后端架构**：

- `api/`：统一后端（单个 Spring Boot）= 若依 RuoYi-Vue 后端模块 + 新增 `shanheng-app` App 业务模块。
- `maneger-web/`：只放若依 Vue 管理前端（`ruoyi-ui`）。
- 认证双轨：管理端走若依原生 Token（`sys_user`），App 端走自定义 JWT（`sh_user`）。
- 数据库：单库，表前缀隔离（`sys_*` / `sh_*`）。

**为什么调整**：
- 两个 Spring Boot 共享一个库会产生"双端写同一批表"的数据归属风险。
- 单后端只需一套部署、一个端口，且若依的用户/权限/日志/代码生成器直接复用。
- 对单人/毕业设计规模，单后端复杂度与维护成本明显更低。

**重要配套调整**：
- 后端技术栈从「Spring Boot 3 + Java 17 + MyBatis-Plus」调整为「若依 RuoYi-Vue 主线：Spring Boot 2.5.x + Java 8 + MyBatis」。
- App 业务模块复用若依 MyBatis 基础设施，不额外混入 MyBatis-Plus（避免冲突）。
