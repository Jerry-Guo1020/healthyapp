## 三、核清的关键事实

1. **密钥/.env 现状**：已配 MySQL/Redis/镜像前缀；华为 client_id/secret 与百度 api/secret key 均为**空**待填；USDA 走默认 `DEMO_KEY` 免费可用。后端密钥均通过 `${环境变量:默认空}` 读取，未配置时返回明确业务错误而非 500。
2. **第三方调用**：华为 Account Kit、华为 Health Service Kit、百度菜品识别、USDA 四类。代码里实际 import 的华为 Kit 只有 AccountKit 与 HealthServiceKit（其余 Push/Map/Safety 是 DevEco 模板默认 capability，未使用）。
3. **收费结论**：除云服务器外全部免费——华为两 Kit 免费不计次；百度有免费额度；USDA 免费；R2 免费额度。
4. **开源替代**：百度→PaddleClas 本地部署；USDA→Open Food Facts / 中国食物成分表本地库；R2→MinIO；华为两 Kit 无开源替代（系统级/品牌 SDK）。
5. **手表对接现状**：前端 `HuaweiHealthService` 只实现「一般权限」步数/卡路里/距离；受限权限（心率/睡眠/压力）代码未接。手机看不到数据的根因是 **AGC 运动健康服务未开通 + 签名 profile 未重新生成**（当前 profile 无 Health Kit 能力），不是代码问题。
