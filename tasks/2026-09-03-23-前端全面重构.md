# 任务 23 · 前端全面重构（登录/健康联动/导航/搜索/启动逻辑）

> 日期：2026-09-03
> 触发：用户对前端 7 大项做定稿优化。

## 一、需求与落地

1. **账户界面**
   - 华为登录按钮文案去掉括号 → "华为账号登录"。
   - 取消手机验证码登录：只保留「一键登录 + 华为账号登录 + 游客体验」。
   - 一键登录 UI 已做：`HuaweiAuthService.quickLogin()`（scope=quickLoginAnonymousPhone），登录页主按钮"一键登录"；权限未通过时降级提示"请使用华为账号登录"。后端 getPhoneNumber 流程待审核通过后补。

2. **健康数据联动（方案：单一入口 + 全局状态）**
   - 新增 `common/HealthAuthState.ets`：授权状态全局缓存 + 持久化。
   - 重构 `HuaweiHealthService.syncAndArchive()`：授权→同步→`HealthAuthState.setAuthorized(true)`→后端记录 auth-status→合并摘要上报，**「我的」与「健康」两个入口统一调用**。
   - 「我的」健康授权卡与「健康」华为同步卡共用同一状态，切 Tab 时 `onActiveChange` 刷新，彻底联动。

3. **关于膳衡页**：新增 `pages/AboutPage.ets`（简介/开发者/版本/协议入口），「我的」关于卡可点击进入。

4. **用户管理**：新增 `pages/AccountManagePage.ets`（账号信息/身份/登录方式/退出登录/游客引导登录），「我的」加入口。

5. **启动与登录逻辑**：`Index.ets` 不再拦登录——恢复会话若有 token 直接进主界面；无 token 则**静默游客登录**后直进主界面。展示类功能游客可用；详细功能（收藏/历史/健康分析/偏好等）经 `common/AuthGuard.requireAccount()` 校验，未登录跳登录页。

6. **导航调整**
   - 收藏/历史移入「我的」作为子页面（`FavoritePage`/`HistoryPage`），不再作底部 Tab。
   - 拍照识食提升为底部主功能：新增 `pages/tab/FoodRecognizeTab.ets`（删除旧 `FoodRecognizePage.ets`）。
   - 底部导航现为 4 Tab：首页 / 识食 / 健康 / 我的。

7. **搜索优化**
   - 首页搜索框点击 → 独立 `pages/SearchPage.ets`（搜索框 + 结果分页列表）。
   - 搜索框内加"✕ 一键清除"按钮。

## 四、健康数据联动方案说明（给用户的答复）

原「我的·健康数据授权」只写后端标记不碰华为；「健康·同步」才真正拉起 Health Kit。现已统一为：
- **唯一入口**：`syncAndArchive`（两处都调它）。
- **唯一状态**：`HealthAuthState`（两页读同一份，切 Tab 即同步）。
- **行为一致**：在「我的」点授权 = 在「健康」点同步，都会授权+同步步数+归档+生成分析。
