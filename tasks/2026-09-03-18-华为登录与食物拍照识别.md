# 任务 18：华为账号登录 + 食物拍照识别 + 健康授权反馈优化

## 日期
2026-09-03

## 背景
用户真机测试反馈三个问题：
1. 健康数据授权：点了授权按钮「没有反应」
2. 登录：(a) 短信验证码是摆设（用户决定：短信要钱不用，改华为账号登录）；(b) 评估并实践华为一键登录
3. 食物照片推荐：之前「通过 API 调第三方资料推荐」没完全做好

## 关键决策
- **放弃短信验证码**（需短信服务商 + 费用），改用**华为账号授权码模式登录**（个人开发者免费可申请，无需企业资质）。
  - 华为「一键登录（ID Token 静默）」需企业资质，个人暂不可用 → 选授权码模式（跳转华为账号授权页）。
- **食物照片识别选百度 AI 菜品识别**：免费额度、国内可达、中文菜品覆盖、返回卡路里；比 PhotoMeal/LogMeal 等英文识别更贴合中式菜品。
- **健康授权**：后端接口本就正常（服务端自测 code 200）；「没反应」根因定位为缺交互反馈 + 真实 Health Kit 未接入 → 本轮加「授权确认弹窗 + loading + 状态切换」，真实 Health Kit SDK 后置（需 AGC + 受限权限审核）。

## 已完成

### 1. 华为账号登录（个人可用，免费）
**后端**：
- `domain/bo/HuaweiLoginBo.java`（新）：code + state。
- `support/HuaweiAccountClient.java`（新）：授权码换 access_token（POST `oauth-login.cloud.huawei.com/oauth2/v3/token`）→ 取用户信息（`rest.php?nsp_svc=GOpen.oauth2.user.getTokenInfo`），解析 openId/unionId/nickname/avatarUrl/phone。
- `service/IAppAuthService` + `AppAuthServiceImpl`：`huaweiLogin(HuaweiLoginBo)`——按 union_id 查 `sh_user_auth`（auth_type=HUAWEI）；已有直接登录，无则建 `sh_user` + 绑定 `sh_user_auth`；华为手机号与已有手机号用户一致时合并。
- `controller/AppAuthController`：新增 `POST /app/v1/auth/huawei-login`。
- `application.yml`：新增 `shanheng.huawei.*`（client-id/client-secret/token-url/userinfo-url，均可环境变量覆盖）。

**前端**：
- `service/HuaweiAuthService.ets`（新）：封装 Account Kit 授权码模式（`authentication.createAuthorizationWithAuthorizationCodeRequest` → execute 拿 code）；`HUAWEI_CLIENT_ID` 留空待填。
- `service/AuthApi.ets`：新增 `huaweiLogin(code, state)`。
- `pages/LoginPage.ets`：新增红色「华为账号登录」按钮（游客登录下方），`onHuaweiLogin` 流程：SDK 拿 code → 后端换登录 → 存 session → 进主页。

### 2. 食物拍照识别（百度 AI 菜品识别）
**后端**：
- `support/BaiduFoodClient.java`（新）：access_token 获取（Redis 缓存 25 天）+ 菜品识别（POST `rest/2.0/image-classify/v2/dish`，top_num=5）；自动剥离 `data:image/...;base64,` 前缀。
- `domain/bo/FoodRecognizeBo.java`（新）：image（base64）。
- `domain/vo/FoodRecognizeVo.java`（新）：name/calorie/probability/hasCalorie/matchedDish/recommends。
- `service/IAppFoodService` + `AppFoodServiceImpl`：百度候选逐个 like 匹配本地 `sh_dish`（status=1）；命中则回传 matchedDish，未命中回传识别菜名 + 热门推荐；推荐优先同分类，否则按 recommendCount 降序。
- `controller/AppFoodController.java`（新）：`POST /app/v1/food/recognize`。
- `application.yml`：新增 `shanheng.baidu.*`（api-key/secret-key）。

**前端**：
- `model/ApiModels.ets`：新增 `FoodRecognizeVo`。
- `service/FoodApi.ets`（新）：`recognize(image)`。
- `common/ImageUtil.ets`（新）：相册 uri → 压缩（短边 800、jpeg 75%）→ base64，失败降级读原图。
- `pages/FoodRecognizePage.ets`（新）：选图（PhotoViewPicker）→ 预览 → 开始识别 → 结果展示（识别菜名 + 卡路里 + 匹配菜品 DishCard + 推荐列表）。
- `pages/tab/HomeTab.ets`：搜索栏下加「📷 拍照识食」入口横幅 → 跳转识别页。

- ✅ 后端编译：服务器 `mvn -pl ruoyi-modules/shanheng-app -am compile` → **BUILD SUCCESS**。

## 需要用户操作的前置条件
1. **华为账号登录**：
   - 注册华为开发者账号（实名认证）
   - AppGallery Connect 创建 HarmonyOS 应用 → 获取 AppID / client_id / client_secret
   - 开通「账号服务」(Account Kit)，勾选 scope：openid + profile
   - 真机调试证书 SHA-256 指纹配置进 AGC
   - 填入：后端环境变量 `SHANHENG_HUAWEI_CLIENT_ID/SECRET` + 前端 `HuaweiAuthService.HUAWEI_CLIENT_ID`
2. **食物识别**：
   - 注册百度智能云，创建应用开通「菜品识别」→ 拿 API Key / Secret Key
   - 填入：后端环境变量 `SHANHENG_BAIDU_API_KEY/SECRET`
3. **健康数据真实授权（P1，需企业资质）**：
   - AGC 开通 Health Service Kit；步数等一般权限个人可申请，睡眠/心率/压力为受限权限需企业审核
   - 真实 SDK 接入后替换当前「确认弹窗 + 记录」形态
