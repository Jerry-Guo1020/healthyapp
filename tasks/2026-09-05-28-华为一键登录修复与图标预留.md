## 二、问题 1 根因与修复（华为一键登录）

### 根因

旧 `HuaweiAuthService.quickLogin()` 用 `authentication.executeRequest(scope=['quickLoginAnonymousPhone'])` 后读 `credential.authorizationCode`，但该 scope 正确返回是 `response.data.extraInfo.quickLoginAnonymousPhone`（匿名手机号），`authorizationCode` 恒为 `undefined`，前端直接 throw，请求未发后端。

### 正确流程（华为官方）

授权码必须通过 `LoginWithHuaweiIDButton` 组件（`LoginType.QUICK_LOGIN`）点击后，在 `onClickLoginWithHuaweiIDButton((error, credential))` 回调里拿 `HuaweiIDCredential.authorizationCode`；`HuaweiIDCredential` 同时直接返回 `unionID`/`openID`。当前登录闭环不依赖手机号，前端直传 `unionId/openId`，后端按 UnionID 直登。

### 修复内容

**后端**（`HuaweiLoginBo.java` / `AppAuthServiceImpl.huaweiLogin`）：
- `HuaweiLoginBo` 支持 `code`（普通授权码）+ `unionId`/`openId`/`nickname`/`avatarUrl`（一键登录组件回调）
- `huaweiLogin` 重写：`code` 非空走 `huaweiAccountClient.login(code)` 换 token 读用户信息；否则用 `unionId` 直登；查绑定/自动注册逻辑复用，final 副本进入 lambda

**前端**：
- `AuthApi.ets`：新增 `HuaweiQuickLoginBody` + `huaweiQuickLogin(unionId, openId)`，仍 POST `/auth/huawei-login`
- `HuaweiAuthService.ets`：删除错误 `quickLogin()`，新增注释说明一键登录需走 `LoginWithHuaweiIDButton`
- `LoginPage.ets`：引入 `loginComponentManager`、`LoginWithHuaweiIDButton`；新增 `quickController`；`aboutToAppear` 绑定协议状态与点击回调；新增 `handleQuickLogin`；「一键登录」Button 替换为 `LoginWithHuaweiIDButton({ params: { style: BUTTON_RED, loginType: QUICK_LOGIN, borderRadius: 26, supportDarkMode: true }, controller })`

错误码区分：`1005300001` 未同意协议、`1001502012` 用户取消、`1001502014` 未申请权限。
