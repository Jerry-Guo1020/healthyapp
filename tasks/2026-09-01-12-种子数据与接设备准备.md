## 二、接设备（真机调试）结论

### 2.1 操作四步

1. **手机**：必须是纯血鸿蒙 HarmonyOS NEXT 真机（非老 EMUI）；设置 → 关于手机连点「版本号」7 次开启开发者模式 → 打开「USB 调试」。
2. **签名**：DevEco `File → Project Structure → Signing Configs`，勾选 *Automatically generate signature*（华为账号登录生成 debug 签名；`com.example.healthyapp` 调试装真机不受限）。
3. **连接**：USB 连电脑 → 手机弹窗「允许 USB 调试」→ DevEco 顶部选中设备 → Run。
4. **联调后端**：真机访问 `http://43.139.91.62:18080`，**需先放行云服务器安全组 18080 端口**（否则游客登录都连不上）。

## 四、接口验证（带 token）

> 澄清：`AppAuthInterceptor` 拦截 `/app/v1/**`，仅放行 `auth/send-code`、`auth/login-by-code`、`auth/guest`、`auth/huawei-login`；其余接口必须带 `Authorization: Bearer <token>`。**不带 token 返回 401（`未登录或登录已过期`）是正常表现**，App 前端游客登录后由 `ApiClient` 自动注入 token。

验证结果：

- `POST /app/v1/auth/guest` → `code:200`，签发 JWT。
- `GET /app/v1/categories`（带 token）→ `code:200`，8 个分类（含 `children`）。
- `GET /app/v1/dishes?pageNum=1&pageSize=2`（带 token）→ `code:200`，`total=16`，records 含 `categoryName`、`ingredients`、`calorie`、`tags`、`favorite` 等完整字段。

样例菜品：菠菜猪肝汤（养胃暖食 / 暖胃·滋补）、鸡丝荞麦面（午餐 / 高蛋白·低脂）。
