## 四、关键决策记录

| 决策 | 结论 | 原因 |
| --- | --- | --- |
| 数据库 | MySQL 8.0（utf8mb4） | 若依原生支持、国内生态成熟、项目以关系表为主 |
| 对象存储 | Cloudflare R2 | 免费 10GB + 无流量费 + S3 兼容 |
| 后端架构 | `api/`（膳衡业务后端）+ `maneger-web/`（若依）双后端，共享 MySQL | 与用户目录规划一致，运营与业务解耦 |
| 数据边界 | 业务配置表由若依写、api 只读；用户数据由 api 写、若依只读 | 防止双后端数据冲突 |
| 登录方案 | P0 验证码 + 游客；华为登录预留 | 个人开发者无法申请一键登录 |
| 健康方案 | Health Kit 后置，先做"手动健康状态"降级 | 规避权限审核周期 |
| App 构建 | 不走 GitHub Actions，本地/华为云构建 | 鸿蒙工具链限制 |
| 管理端目录 | `maneger-web/` 放若依完整仓库（前后端） | 不新增目录 |
