### 2. mock 数据核查
前端无任何 mock 假数据：首页分类/菜品、搜索、转盘、推荐流、健康分析均通过 `BizApi` / `RecommendApi` / `HealthApi` 请求后端接口取数（数据存 `sh_*` 表，由若依管理端维护）。页面内仅保留合法的固定枚举选项（健康目标/口味/菜系/忌口快捷项），属 UI 选项清单而非 mock。

### 3. 登录/游客态区分
- `UserSession` 新增 `isLoggedInUser()`：`isLogin() && !isGuest()`。
- 「我的」页顶部 `userCard` 二分：
  - **未登录/游客** → 显示「🔒 未登录，请登录」占位，点击跳登录页；
  - **正式登录** → 显示头像 + 昵称 + 「已登录用户」。
- 移除「我的」页的「游客模式」字眼（正式版 UFO 无游客）。

### 4. 用户管理登录拦截
- ProfileTab `enterAccount()` 增加 `AuthGuard.requireAccount()`，与「我的收藏」「浏览历史」一致：未登录/游客直接跳登录页。
- AccountManagePage 内部文案「游客模式→未登录」规范化。
