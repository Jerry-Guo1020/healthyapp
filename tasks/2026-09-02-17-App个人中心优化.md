# 任务 17：App「我的」页优化（偏好/忌口/健康授权 + 预算推荐联动）

## 日期
2026-09-02

## 目标
补齐 App「我的」页（ProfileTab）的功能缺口——此前仅「头像 + 关于 + 退出登录」，本次把后端已就绪但前端未接的「饮食偏好 / 忌口管理 / 健康授权」全部落地，并让预算偏好真正参与推荐闭环。

## 背景（后端已就绪，前端缺失）
- `UserApi`（getPreference/savePreference/listAvoid/addAvoid/removeAvoid）与 `HealthApi`（authStatus/revokeAuth）早已实现，ProfileTab 未接。
- `healthGoal` 枚举（UserPreferenceBo 注释）：`LOSE_FAT`（减脂）/ `MUSCLE_GAIN`（增肌）/ `STOMACH`（养胃）/ `SUGAR_CONTROL`（控糖）。
- 忌口 `itemName` 自由文本，推荐引擎按「标签名 / 食材清单」双向 contains 硬过滤。
- 预算 `budgetMin/budgetMax` 在推荐侧按区间重叠过滤（`ge(price_max,budgetMin)` + `le(price_min,budgetMax)`）。
- 健康授权：`POST /health/auth-status`（授权，写一条 status=1 记录 + 旧记录置失效）、`POST /user/revoke-health-auth`（撤销）。

## 实现

### 1. ProfileTab.ets 重构
- 分层：用户卡片 → 饮食偏好卡 → 我的忌口卡 → 健康数据授权卡 → 关于 → 退出登录，整体套 `Scroll`。
- **饮食偏好**：折叠卡片，摘要行显示「健康目标 + 口味/菜系已选项数」；展开后：
  - 健康目标单选 chips（减脂/增肌/养胃/控糖，可再点取消 = 空）
  - 口味多选 chips（清淡/微辣/重口/少油/咸鲜）
  - 菜系多选 chips（粤菜/川菜/家常菜/轻食/面食）
  - 预算区间两个 TextInput（最低/最高价）
  - 「保存偏好」→ `savePreference`，taste/cuisine 存 `JSON.stringify(string[])`，budget 空则传 0
- **我的忌口**：已添加忌口 chips（点 ✕ 删除）+ 快捷添加（花生/海鲜/辣/乳制品/麸质/羊肉）+ 自定义输入框 + 「添加」。
- **健康授权**：状态（已授权/未授权）+ 授权/取消按钮；授权 scope 传 `['STEPS','SLEEP','HEART_RATE','STRESS','ACTIVITY']`（P1 预留）。
- ArkTS 严格模式落实：模块级 const 选项数组、显式 class 请求体（PreferenceBody/AvoidBody/HealthAuthStatusBody）、`JSON.parse as string[]`、数组整赋（filter/concat）、ForEach 字符串 key。

### 2. HealthTab.ets 预算联动（推荐闭环）
- `doRecommend()` 改为先 `UserApi.getPreference()` 读偏好，将 `budgetMin/budgetMax` 注入 `RecommendBody`，再 `RecommendApi.recommend()`——用户设置的预算真正参与推荐过滤。

## 服务器端到端验证（guest token，全部通过）
1. `GET /user/preference` 初始 `data=null` ✅
2. `PUT /user/preference`（taste `["清淡","少油"]`、cuisine `["粤菜","轻食"]`、预算 20-30、healthGoal LOSE_FAT）→ code 200 ✅
3. 回读偏好字段完整（budget 序列化为 `20.00/30.00`，前端 number 无损）✅
4. `POST /user/avoid`（"辣"）→ code 200，返回 id ✅
5. `GET /user/avoid` 列表 1 条 ✅
6. `POST /recommendations`（budget 10-15）→ 返回菜全部满足 `priceMin<=15 && priceMax>=10` ✅
7. `POST /recommendations`（budget 20-30）→ 返回 20-30 区间重叠的菜，且**麻婆豆腐（22-26，带"辣味"标签）被忌口"辣"硬过滤排除** ✅

## 关键决策
- **健康目标枚举前端固定 4 项**：与 UserPreferenceBo 注释一致；未选 = 空字符串（后端存空）。
- **taste/cuisine 存 JSON 数组字符串**：与后端字段注释「JSON 字符串」一致；推荐引擎当前不消费 taste/cuisine（只消费 healthGoal 与忌口），此处作为展示与后续扩展保留。
- **预算区间过滤语义为「价格区间重叠」**：后端 `ge(price_max,budgetMin)` + `le(price_min,budgetMax)`，前端无需特殊处理。
- **健康授权为 P1 预留**：无查询接口（仅 write），前端用内存 @State 展示状态；真实华为 Account Kit / Health Kit 接入后再带 source=HEALTH_KIT 数据切换。
- **忌口硬过滤与 useHealthData 无关**：`applyAvoidFilter` 始终执行，验证中"辣"排除麻婆豆腐已证实。
