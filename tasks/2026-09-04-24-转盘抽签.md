# 任务 24 · 转盘抽签功能

> 日期：2026-09-04
> 触发：用户确认实施「转盘抽签」（三大支柱之一，零外部依赖）。

## 一、设计

- 后端随机接口：`GET /app/v1/dishes/random?count=6[&categoryId=]`
  - 返回随机 N 道菜（count 夹在 1-12，默认 6），`ORDER BY RAND() LIMIT n`，复用 `DishAssembler` 补全分类名/标签/收藏态。
- 前端转盘：`pages/WheelPage.ets`
  - Canvas 绘制扇形转盘（6 格彩色 + 菜品名径向文字 + 中心圆点），顶部固定指针。
  - 点击「开始抽签」→ `animateTo` 旋转 Canvas 组件 5 圈多，精确停在随机目标扇形，`onFinish` 展示结果卡。
  - 结果卡：「再抽一次」「去查看」跳详情页。
  - 「换一批」重拉随机候选。

## 二、文件变更

- 后端：`IAppDishService.randomList()`、`AppDishServiceImpl` 实现、`AppDishController` 加 `GET /dishes/random`。
- 前端：`BizApi.randomDishes()`、新增 `pages/WheelPage.ets`、`HomeTab` 加「转盘抽签」入口横幅、`main_pages.json` 注册。

## 三、验证

- GitHub Actions `api-ci` 对 `7d38336` 构建 success（后端编译+打包+推镜像）。
- 服务器实测：guest 登录 → `GET /app/v1/dishes/random?count=6` 返回 `code:200`，含 6 道完整菜品（麻婆豆腐/鸡丝荞麦面/白灼虾/蒸红薯紫薯…），字段完整。
