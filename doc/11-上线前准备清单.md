# 11 · 上线前准备清单

## 一、华为侧资质与申请

| 项 | 说明 | 状态 |
| --- | --- | --- |
| 华为开发者账号 | 注册实名（个人/企业） | ☐ |
| 企业开发者认证 | 一键登录必需（个人开发者无法申请） | ☐ |
| AppGallery Connect 创建应用 | 包名 `com.example.healthyapp` 需替换为正式包名 | ☐ |
| Account Kit 开通 | 登录服务（如用一键登录需企业资质） | ☐ |
| Health Service Kit 开通 | 权限申请（步数/睡眠/心率/压力） | ☐ |
| 受限权限审核 | 睡眠/心率/压力等受限权限提交材料 | ☐ |
| 签名配置 | 正式签名（.p12/.cer） | ☐ |

> 注意：正式包名不能是 `com.example.*`，需在 AppGallery Connect 注册并同步修改 `app.json5`。
