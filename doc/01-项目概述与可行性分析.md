# 01 · 项目概述与可行性分析

## 一、项目概述

**项目名称**：膳衡 App（HealthyApp）
**Slogan**：懂你的健康，也懂你的胃。
**产品形态**：纯血鸿蒙（HarmonyOS NEXT）原生 App + Spring Boot 后端 + 若依管理后台。

膳衡是一个面向华为生态用户的「健康饮食决策平台」：

- **核心场景 1**：纠结"今天吃什么"的用户，通过餐次、菜系、口味、健康目标快速找到菜品。
- **核心场景 2**：有华为手表/手环的用户，授权运动健康数据后，获得结合睡眠、压力、心率、步数的个性化饮食建议。
- **核心原则**：健康数据是增强项而非门槛；饮食建议是生活辅助，不是医疗诊断。

---

## 二、可行性判断

### 总体结论：**可行，但需按"菜单发现先行、健康数据后置"的节奏推进**

| 维度 | 评估 | 结论 |
| --- | --- | --- |
| 技术可行性 | HarmonyOS NEXT + ArkTS/ArkUI 开发链路成熟；Spring Boot + MySQL + Redis 是成熟组合；Account Kit / Health Kit 均有官方 SDK 与文档 | ✅ 高 |
| 产品可行性 | "吃什么"是高频刚需；健康饮食是稳定增长赛道；华为生态用户画像清晰 | ✅ 高 |
| 数据可行性 | Health Kit 可读取步数/睡眠/心率/压力等数据，但受限权限需审核 | ⚠️ 中（依赖审核） |
| 商业/账号可行性 | 华为一键登录仅**企业开发者**可申请；个人开发者需用验证码登录 + 游客模式先行 | ⚠️ 中（个人开发者受限） |
| 合规可行性 | 健康数据属敏感个人信息，需隐私政策、单独授权、可撤回；饮食建议不得医疗化表述 | ✅ 可控，但必须严格执行 |
| 资源可行性 | 单人可完成 MVP；云服务器 + 域名 + 软著等有一定成本 | ✅ 可控 |

**一句话判断**：作为毕业设计/企业立项项目完全可行；作为上架商用产品，核心卡点是**企业开发者资质**与**Health Kit 权限审核周期**，需要前置准备。

---

## 三、主要风险与前置依赖（详见 `12-风险分析与解决方案.md`）

1. **个人开发者无法申请 Account Kit 一键登录** → MVP 阶段用「验证码登录 + 游客模式」，华为登录接口预留、企业资质到位后切换。
2. **Health Kit 受限权限（睡眠/心率/压力）需审核** → 步数/活动类权限先申请，敏感权限并行走审核；审核未过前，前端用"手动输入健康状态"降级。
3. **健康数据有延迟、非医疗级** → 产品文案明确"仅供参考"，后端只存摘要不存原始数据。
4. **菜品图片版权** → 优先自有拍摄/免费可商用图源，管理端做内容审核。

## 四、产品定位优化建议

### 原定位的问题

原描述"健康数据 + 饮食推荐 + 菜单发现"三者并列，容易让人困惑：
- 用户第一眼不知道 App 是"健康工具"还是"菜谱工具"；
- 健康数据门槛会让无手表用户流失；
- 价值主张不够尖锐。

### 优化后的定位

> **膳衡 = 华为用户的"吃什么"决策助手。先解决选择困难，再用健康数据让建议更懂你。**

### 定位三句话

1. **一句话定位**：帮你决定"这一餐吃什么"的鸿蒙健康饮食助手。
2. **给无手表用户**：按时间、场景、口味、目标快速找到想吃的东西。
3. **给有手表用户**：读你的睡眠、压力、活动量，告诉你"今天更适合吃什么"。

### 定位边界（明确"不做什么"）

- ❌ 不做医疗诊断、不声称疗效（合规红线）
- ❌ MVP 不做外卖下单/配送（只做内容与推荐，下单可跳转第三方或后续版本）
- ❌ 不做 UGC 社区（首版菜品由运营/管理端录入，保证质量）
- ❌ 不做计步/睡眠监测采集（只读华为健康数据，不自研采集）

### 差异化卖点

| 对比维度 | 普通菜谱 App | 膳衡 |
| --- | --- | --- |
| 决策方式 | 用户自己翻分类/搜索 | 场景 + 偏好 + 健康数据自动推荐 |
| 健康结合 | 静态标签（低脂/高蛋白） | 动态摘要（昨晚睡眠差 → 推荐清淡暖胃） |
| 鸿蒙生态 | 无 | Account Kit + Health Kit 原生集成 |

## 五、结论与建议路线

**建议路线（分三步走）**：

1. **第一步（MVP 上架）**：菜单发现 + 验证码登录 + 游客模式 + 规则推荐 + 管理后台。先让"没有手表也能用"成立。
2. **第二步（增强）**：企业开发者资质到位后接 Account Kit 一键登录；Health Kit 接入步数/睡眠/心率/压力摘要推荐。
3. **第三步（精细化）**：推荐反馈闭环、个性化权重学习、更多健康指标（血氧/体温/HRV）与运营位。
